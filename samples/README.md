# Sample model

`RhinoRoad-vehicle-access.3dm` was generated by the release plugin's `RRVehicleAccessSample` command
in Rhino 8. It contains a PV mode-B quarter-turn study with rear/front axle tracks, body and clearance
envelopes, fixed-width road edges, RhinoRoad layers, grouping, and metadata. Run the command in an
empty metric document and save the result here when refreshing the sample.
